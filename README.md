# PRIV 경매·NPL 실전 계산기

**라이브:** https://priv-npl.github.io/priv-npl-calculator/

경매 낙찰·경락잔금대출·취득세, NPL 질권대출 레버리지 ROE, 순위별 배당표를 한 화면에서 계산하는 정적 웹앱입니다.
외부 백엔드·라이브러리·CDN 의존성이 없어 `index.html` 하나만 열어도 동작합니다.

## 구성

```
index.html            화면(3개 탭 + 문의 CTA)
assets/styles.css     디자인(모바일 퍼스트, 인쇄용 CSS 포함)
assets/app.js         계산 엔진 및 UI 로직
```

## 계산 기준

### 탭 1 · 경매 낙찰가 · 경락잔금대출 · 취득세
- 낙찰가율 = 입찰가 ÷ 감정가 × 100
- 대출한도 = min(감정가 × LTV, 낙찰가 × 낙찰가비율) − 방공제 (1금융권 관행: 감정가 70%·낙찰가 80%)
- 취득세(지방세법)
  - 주택 1주택: 6억 이하 1% / 6억 초과~9억 이하 `(가액억 × 2/3 − 3)%` 누진 / 9억 초과 3%
  - 주택 중과: 8%(조정 2주택·비조정 3주택), 12%(조정 3주택 이상·법인)
  - 지방교육세: 1~3% 구간은 취득세의 10%, 중과는 0.4% 고정
  - 농어촌특별세: 전용 85㎡ 초과 시 0.2% (8% 중과 0.6%, 12% 중과 1.0%)
  - 오피스텔·상가·토지: 4% + 0.4% + 0.2% = 4.6%
  - 세목별 10원 미만 절사
- 총 필요 현금 = (낙찰가 − 대출) + 취득세 + 법무사·명도·수리비
- 연 순수익률 = (연 임대수익 − 대출이자) ÷ 총 필요 현금 × 100

### 탭 2 · NPL 질권대출 · ROE
- 질권대출액 = 기준가(채권매입가 또는 담보 감정가) × LTV
- 투입 자기자본 = 매입가 + 매입 부대비용 − 질권대출액
- 총 회수액 = 채권원금 × 회수율 + 채권원금 × 채권이자율 × 기간/12
- 순수익 = 총 회수액 − 매입가 − 질권대출 이자 − 매입 부대비용
- 연환산 ROE = 순수익 ÷ 자기자본 × 100 × (12 ÷ 회수 개월)

### 탭 3 · 배당표
- 배당 순서: 집행비용 → 당해세 → 소액임차인 최우선변제 → 선순위 임차인 → 1순위 근저당 (남은 금액만 배분)
- 1순위 회수율 = 근저당 배당액 ÷ 채권최고액 (실제 채권액 입력 시 실채권 기준 회수율도 표시)

## 배포

정적 파일 3개이므로 어느 정적 호스팅에나 그대로 올릴 수 있습니다.

```bash
# GitHub Pages (공개 리포지토리)
gh repo create priv-npl-calculator --public --source=. --remote=origin --push
gh api -X POST repos/:owner/priv-npl-calculator/pages \
  -f 'source[branch]=main' -f 'source[path]=/' -f build_type=legacy
# → https://<owner>.github.io/priv-npl-calculator/
```
